### Features

* **core:** initial Rust port of [n2words](https://github.com/forzagreen/n2words):
  cardinal, ordinal and currency forms for 50 languages (72 regional variants),
  arbitrary-precision input, per-language typed options, a runtime language
  registry and the `n2words` command-line tool.
